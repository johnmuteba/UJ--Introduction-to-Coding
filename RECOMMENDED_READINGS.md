## Core Textbooks

### Required Texts

#### 1. Bite-size Python: An Introduction to Python Programming

**Author:** Speight, April
**Year:** 2020
**Publisher:** John Wiley & Sons, Inc., Indianapolis, Indiana
**Publication Location:** Published simultaneously in Canada and USA
**ISBN:** 978-1-119-64381-4 (Hard Copy)
**ISBN:** 978-1-119-64383-8 (eBook)

**Coverage:** Chapters 1-14
- Variables, Lists, Tuples, Strings
- Functions, Loops, Iterations
- Python Modules and Programming Fundamentals

**Why This Book:**
Excellent introductory text for beginners with clear explanations and practical examples. Ideal for students with limited programming experience.

---

#### 2. Python for Data Analysis

**Author:** McKinney, Wes
**Edition:** 2nd edition
**Year:** 2017
**Publisher:** O'Reilly Media

**Key Topics:**
- NumPy fundamentals
- Pandas data structures
- Data loading and preparation
- Data wrangling
- Data aggregation and group operations
- Time series analysis
- Advanced pandas techniques

**Why This Book:**
Written by the creator of pandas, this is the definitive guide to data manipulation in Python. Essential for anyone working with data.

---

#### 3. Python Data Analytics

**Author:** Nelli, Fabio
**Year:** 2015
**Publisher:** Apress
**ISBN:** 978-1-4842-0959-2 (pbk)
**ISBN:** 978-1-4842-0958-5 (electronic)

**Subtitle:** Data Analysis and Science Using Pandas, Matplotlib, and the Python Programming Language

**Key Topics:**
- Introduction to data analysis
- NumPy library
- Pandas library for data manipulation
- Matplotlib for visualization
- Machine learning with scikit-learn
- Deep learning introduction

**Why This Book:**
Comprehensive coverage of the Python data science ecosystem with practical examples.

---

#### 4. Natural Language Processing

**Authors:** Rafail, Patrick and Freitas, Isaac
**Year:** 2020
**ISBN:** 9781529749120 (Online)

**Key Topics:**
- Text preprocessing techniques
- Text vectorization methods
- Topic modeling
- Sentiment analysis
- Applications in social sciences

**Why This Book:**
Excellent introduction to NLP with practical applications relevant to financial text analysis.

---

#### 5. Introduction to Scientific Programming with Python

**Author:** Sundnes, Joakim
**Year:** 2020
**Series:** Simula Springer Briefs on Computing
**ISBN:** 978-3-030-50355-0 (Hard Copy)
**ISBN:** 978-3-030-50356-7 (eBook)

**Key Topics:**
- Scientific computing with Python
- Numerical methods
- Object-oriented programming
- Testing and debugging

**Why This Book:**
Bridges the gap between basic programming and scientific computing, valuable for quantitative finance applications.

---

#### 6. Database Management Systems

**Authors:** Ramakrishnan, Raghu and Gehrke, Johannes
**Edition:** 3rd edition

## Reading Strategy

### For Beginners

**Week 1-2:**
- Speight (2020) - Chapters 1-8
- Python.org tutorials

**Week 3-4:**
- Speight (2020) - Chapters 9-14
- Online Python exercises

**Week 5-6:**
- McKinney (2017) - Pandas fundamentals
- Nelli (2015) - Data manipulation chapters

**Focus on:**
- McKinney (2017) - Complete reading
- Müller & Guido (2016) - Machine Learning basics
- Géron (2022) - Hands-on ML projects
- Rafail & Freitas (2020) - NLP fundamentals

### For Advanced Students

**Focus on:**
- Goodfellow et al. (2016) - Deep Learning theory
- López de Prado (2018) - Advanced financial ML
- Academic papers in your area of interest
- Cutting-edge research on arXiv

## Additional Notes

### Open Access
Many resources are freely available. Take advantage of:
- arXiv preprints
- University library access
- Open-source textbooks
- Free online courses

### Practical Learning
**Balance reading with doing:**
- Read theory → Implement in code → Apply to problems
- Don't just read—code along with examples
- Work on projects to solidify understanding

### Building Your Library
**Priority order for purchasing:**
1. Core textbooks (as listed above)
2. Domain-specific books (finance, NLP, or deep learning based on interest)
3. Reference books for looking up specific topics
4. Advanced texts for specialized research
